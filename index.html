GitHub Pages 只托管静态文件，没有数据库，网页也不能直接写服务器。做法是：把数据做成一个 JSON 文件放进仓库，网页打开时读取它；填了访问令牌后，还能在网页里一键提交回仓库。

Fine-grained 访问令牌 只授予该仓库 Contents 读写
找不到入口？直接打开令牌创建页（自动预填名称、90 天、Contents 读写） · 打开我的令牌列表
入口在账号设置（右上角头像 → Settings → 左侧栏最底部 Developer settings），不是仓库里的 Settings。
请注意
公开仓库 + Pages 意味着提示词和参考图全网可读，不要放敏感内容。令牌只保存在这台设备的浏览器里，不会写进仓库；共用电脑或页面存在恶意脚本时仍有泄漏风险，请使用限定单仓库的 fine-grained 令牌。写入后 Pages 需要重新构建，通常 1–2 分钟后生效。
部署步骤
  1. 把 index.html 放到仓库根目录，Settings → Pages → 从 main 分支 /root 发布。
  2. 在仓库根目录加一个空的 .nojekyll 文件（跳过 Jekyll，避免静态文件被额外处理）。
  3. 点「发布到 GitHub」自动生成 data/prompts.json；或点「导出发布包」，把 prompts.json 手动放进仓库再 push。
  4. 之后任何设备打开同一个网址，都会读到同一份数据。
